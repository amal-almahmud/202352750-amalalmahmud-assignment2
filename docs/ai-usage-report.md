# AI Usage Report

## Tools Used and Use Cases

### ChatGPT

I used ChatGPT for planning, explanations, code review, debugging, testing guidance, Git and GitHub guidance, and documentation support.

ChatGPT also helped me understand the HTML, CSS, and JavaScript code.

In Assignment 2, ChatGPT helped me create the Skills circle, adjust the typing effect, improve form validation, and fix the layout on smaller screens.

### Kilo Code

I used Kilo Code in Assignment 1 to generate an initial semantic HTML structure and responsive CSS design.

The generated code was reviewed and modified before being used in the project. Assignment 2 builds on this version.

## Benefits and Challenges

### Benefits

AI helped me organize the project, understand unfamiliar code, find errors, and improve the design.

It also helped me learn how to use browser DevTools, test form validation, and create meaningful Git commits.

For this phase, AI helped me turn my ideas into interactive features and improve them based on the results I saw in the browser.

### Challenges

Some AI suggestions were longer or more complex than the assignment required.

The Skills styles were initially inside a small-screen media query, which stopped them from appearing on larger screens.

The Home section also needed changes because the text and typing box were still beside each other on a small screen.

During Assignment 1, Kilo Code had tool and connection errors. Some generated image paths referred to files that did not exist, which caused 404 errors until the correct images were added.

## Learning Outcomes

I learned how semantic HTML organizes a page and how Flexbox, CSS Grid, and media queries control the layout.

I also learned more about JavaScript events, form validation, and status messages.

The Skills feature helped me understand how JavaScript can add or remove a CSS class to show and hide content.

I improved my understanding of Git commits, GitHub pushes, browser Console errors, and responsive testing.

## Responsible Use and Modifications

I reviewed AI suggestions, tested parts of the website in the browser, changed personal content, and simplified unnecessary parts.

I asked for the typing effect to clear the whole phrase at once because I did not want it to disappear letter by letter.

I also asked for errors to appear below each form field, with one general message when all fields are empty.

The name validation was improved to reject numbers while supporting Arabic and English letters.

After the mobile layout changes, I checked the Home section in a small-screen browser preview. The navigation links, buttons, and typing box were visible.

More testing is still needed for the Skills interaction in the mobile preview, specific screen widths, and another browser.

## Innovation

The Skills circle was my idea. I wanted the skills to appear around a central circle when the user interacts with it, and AI helped me build this behavior.

AI also helped me adjust the typing effect and form feedback to match the experience I wanted.

During Assignment 1, AI helped create placeholder project previews that matched the website design.

These changes show how I used AI to develop my ideas and solve problems during the project.
