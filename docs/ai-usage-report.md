# AI Usage Report

## Tools Used and Use Cases

### ChatGPT

I used ChatGPT for planning and explanations and code review and debugging and testing guidance and Git and GitHub guidance and documentation support

ChatGPT also helped me understand the HTML and CSS and JavaScript code instead of only providing code to copy

### Kilo Code

I used Kilo Code to generate an initial semantic HTML structure and responsive CSS design

The generated code was reviewed and modified before being used in the final project

## Benefits and Challenges

### Benefits

AI helped me organize the project and understand unfamiliar code and find errors and improve the responsive design

It also helped me learn how to use browser DevTools and test form validation and create meaningful Git commits

### Challenges

Some AI suggestions were longer or more complex than the assignment required

Kilo Code had tool and connection errors while editing files

Some generated image paths referred to files that did not exist which caused `404` errors until the correct images were added

## Learning Outcomes

I learned how semantic HTML organizes a web page and how Flexbox and CSS Grid and media queries create a responsive layout

 also learned how JavaScript events and form validation and status messages work

 improved my understanding of Git commits and GitHub pushes and browser Console errors and responsive testing

## Responsible Use and Modifications

I did not accept every AI suggestion automatically

I reviewed the code and tested it in the browser and changed personal content and simplified unnecessary parts and corrected errors before adding the code to the project

 also i improved the contact form so names containing numbers are rejected while Arabic and English letters are supported

## Innovation

AI was used to create original placeholder previews that match the website design

AI was also used to improve the name validation and investigate responsive breakpoints and identify the difference between project errors and Live Server errors

These changes show how AI supported problem solving rather than only generating code
