# 202352750-amalalmahmud-assignment1




## Project Description

This project is simple and responsive personal portfolio website created for Assignment 1.It includes About Me,Skills,Projects and Contact sections

The website displays two project concepts with placeholder images and includes a contact form with JavaScript validation and user feedback.The layout adapts to desktop,tablet and mobile screen sizes

## Setup Instructions

The project does not require installing any packages or dependencies

1. Download the repository or clone it using:

```bash
git clone https://github.com/amal-almahmud/202352750-amalalmahmud-assignment1.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.

The website can also be opened in Visual Studio Code using the Live Server extension.

## How to Use

- Use the navigation links to move between the website sections.
- Select **View My Projects** to open the Projects section.
- Complete the Name, Email, and Message fields to test the contact form.
- Select **Send Message** to view the validation feedback.

The contact form is a demonstration only and does not send information to a server.
